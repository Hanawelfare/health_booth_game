# 🏥 Health Booth Game System (ระบบเกมบูธสุขภาพ 2 วัน)

ระบบเกมประลองสุขภาพสำหรับบูธกิจกรรมบริษัท ออกแบบให้พนักงานสแกน QR Code เพื่อเข้าแข่งขันพร้อมกันได้สูงสุด 10 คนต่อรอบ โดย**ไม่ต้องใช้หน้าจอทีวี**ที่บูธ รองรับทั้งมือถือ แท็บเล็ต/iPad และคอมพิวเตอร์อย่างลื่นไหล

---

## 🌟 ฟังก์ชันเด่นของระบบ

1. **สแกน 1 QR Code เดียวตลอดทั้ง 2 วัน:**
   - พนักงานสแกนป้ายบนโต๊ะบูธ กรอก **รหัสพนักงาน + ชื่อเล่น + เลือก Avatar** เพื่อเข้าสู่ห้องรอ
2. **ระบบสุ่มคำถาม 10 ข้อ & สุ่มชอยส์ (ป้องกันการจำคำตอบ):**
   - มีคลังคำถามสุขภาพมาตรฐาน **30 ข้อ** สุ่มหยิบ 10 ข้อในแต่ละรอบ และสลับตำแหน่งตัวเลือก (A, B, C, D) ทุกครั้งที่เล่นซ้ำ
3. **ระบบจัดการคำถาม (Question Bank CRUD ในหน้า Admin):**
   - แอดมินสามารถ **เพิ่ม, แก้ไข, ลบคำถาม** ได้ง่ายๆ ผ่านหน้าเว็บโดยไม่ต้องแตะโค้ด พร้อมปุ่มรีเซ็ตเป็น 30 ข้อมาตรฐานได้ตลอดเวลา
4. **4 โหมดเกมให้แอดมินเลือกสลับความสนุก:**
   - 🧠 **Speed Health Quiz:** ตอบคำถามสุขภาพ 10 ข้อ แข่งความเร็วและคะแนน
   - 🔥 **Calorie Burner Tap:** แตะหน้าจอรัวๆ 30 วินาที เบิร์นแคลอรี่สะใจพร้อมโหมดไฟลุก Fever!
   - 🧺 **Healthy Catch:** ลากตะกร้าเก็บผลไม้ หลบของทอด 30 วินาที
   - 👆 **Healthy Swipe:** การ์ดพฤติกรรม ปัดซ้าย/ขวา ทำคอมโบ 30 วินาที
5. **แก้ปัญหาบูธไม่มีจอทีวี (Mobile-First Display):**
   - จบเกม อันดับ 1–10 จะเด้งขึ้นบนมือถือของพนักงานทุกคนทันที
   - คนที่ชนะรางวัลจะมี **ป้ายสีทอง "ยินดีด้วย! คุณได้รับรางวัล แสดงหน้าจอนี้แก่เจ้าหน้าที่บูธ"** พร้อมเสียงเพลง Fanfare ชัยชนะ และเอฟเฟกต์ Confetti ฉลอง
6. **กติกาแจกรางวัลตามจำนวนคนแบบอัตโนมัติ:**
   - **ผู้เล่น 1–3 คน:** แจกรางวัลเฉพาะ **อันดับ 1** 🥇
   - **ผู้เล่น 4–10 คน:** แจกรางวัล **อันดับ 1, 2 และ 3** 🥇🥈🥉
7. **ส่งออกรายงาน Excel (CSV UTF-8):**
   - ดาวน์โหลดประวัติผู้เล่น วันเวลา รหัสพนักงาน คะแนน อันดับ และสถานะรับรางวัล เปิดใน Microsoft Excel ภาษาไทยไม่เพี้ยน

1. เปิดโปรแกรม **PowerShell** ในเครื่องคอมพิวเตอร์ประจำบูธ
2. ไปที่โฟลเดอร์โปรเจกต์:
   ```powershell
   cd "C:\Users\MIS\.gemini\antigravity-ide\scratch\health_booth_game"
   powershell -ExecutionPolicy Bypass -File .\server.ps1
   ```
3. บนหน้าจอจะแสดง:
   - **URL สำหรับพนักงาน:** เช่น `http://192.168.1.50:8088/` (นำไปสร้างเป็น QR Code หรือกดเปิดหน้า Admin เพื่อแสดง QR Code)
   - **URL สำหรับแอดมิน:** เช่น `http://192.168.1.50:8088/admin.html`
4. พนักงานที่เชื่อมต่อ Wi-Fi เดียวกันหรือแชร์ Hotspot จากโน้ตบุ๊กสามารถสแกนเล่นพร้อมกันได้จากมือถือจริงทันที!
